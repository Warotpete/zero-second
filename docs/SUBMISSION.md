**Description** (Markdown)
```markdown
### What it is
Zero Second is a real-time newsroom engine for clubs and broadcasters. Most AI football tools explain a moment after it happens. Zero Second continuously forecasts the storylines that **could** happen next, prepares verified content for them **before** they happen, lets a producer pre-approve it, and publishes instantly when the moment arrives, with every prediction tracked to its outcome (Happened, Near miss, Ruled out, Unresolved).

### The problem
Club and broadcaster media teams already pre-make graphics for obvious moments by hand. AI tools in the market react after the event. Verification, translation, sign-off and graphics are the slow part, so content is either late or unchecked.

### How it works
- **PitchForge** generates a seeded synthetic season and live match in an Opta-style event format (passes, pressures, tackles, shots, cards, subs, sprints, physical data).
- **Stats Engine** computes xG, pass difficulty, ball and shot speed, player sprint and distance tags, momentum and a control-vs-chaos index. Numbers are never generated by AI.
- **Season Memory** stores records, streaks, player arcs and head-to-heads, each with a citable fact id.
- **Story Radar** ranks storylines by probability × impact with a documented Poisson model fitted on training matches and evaluated on 200 held-out matches (26% Brier skill).
- **Agents on Microsoft Foundry via Microsoft Agent Framework**: an Editor (uses our MCP server for stats and memory), a Writer (analyst, casual and broadcast-overlay versions, with live slots filled at the moment), a Verifier (code + agent; rejects any number or player not in the facts pack and sends drafts back for redraft, with a deterministic fallback), and a Recap agent with citations.
- **Media Desk** for producers (rundown, pre-approval, agent trace, audit log, recap) and a mobile **Fan View** (moments, "Watch for" forecasts, Casual/Analyst, follow a player, favourite club).
- Timed, machine-readable **overlay JSON** for graphics partners.

### Microsoft technology
Microsoft Foundry (models), Microsoft Agent Framework (agents, tools, MCP client), Model Context Protocol server, Azure Container Apps, Azure Container Registry, managed identity with Azure RBAC, GitHub.

### Why enterprise-ready
Human approval before publishing; hold/edit/revoke with re-verification; fault-injection test mode; timeouts and fallbacks; a full audit log and per-storyline agent trace; keyless access to Foundry; overlay output in a stable JSON format; every number traceable to the Stats Engine or Season Memory.

Press Play or Jump to 66', 78' and FT. Use `?room=yourname` for your own private match, and "New match → Random seed" to see that nothing is scripted.
